# Project history

Short timeline of SkyGuard / Project Furnace work. Dates are Europe/Berlin (UTC+1) unless noted.

## 2026-09 — early prototypes

- First git bundles and Windows / Android experiments
- PixEagle CV tracking fork used as a vision bridge

## 2026-10 — private monorepo (`skyguard`)

- Unified Android Pixel client (builds through 1.8.x)
- Windows Centrum (1.0.0 → 1.2.1)
- Laptop edge stack, realtime DSP package, acoustic C-UAS reference
- Many feature branches: RF/Remote ID, fusion scores, evidence hash chain, installers

Details of that history live in `extras/github-android-summary/`.

## 2026-11 — Project Furnace package

- C4ISR-style fusion engine v7 (PCL ECA-B, GCC-PHAT acoustics, ARUKF, CoT)
- Blackbox TCP hub, Pixel/PTZ trackers, certification document templates
- Cloud / Cloud Shell bootstrap scripts and `skyguard` CLI
- Emulation mode, evidence HTTP API, Docker/Makefile/CI for a self-contained demo

## This public mirror (v1.1.0)

Runnable Furnace core + selected extras + screenshots. Private field notes and large binaries stay out of the tree.
